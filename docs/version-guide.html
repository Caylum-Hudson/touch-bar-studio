TOUCH BAR STUDIO / RELEASE GUIDE

A version for every finished update.

Use three numbers: major.minor.patch. Save everyday work as Git commits.

New feature

1.0.0
Ready for daily use

Core workflows are tested, dependable and ready to rely on.

Make changes → Update version → Build & check → Tag → Release
The version is prepared before the release build. Tags keep old source snapshots available.
Not decimals: 0.9.0 → 0.10.0 is valid. New fixes get new versions; published tags stay unchanged.
