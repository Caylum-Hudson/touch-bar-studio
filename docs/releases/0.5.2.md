# Focused Studio workspace

Version **0.5.2** gives the main Touch Bar preview and icon-based control library more room, while secondary options start collapsed. The native Control Strip is available as a separate preview widget that can be placed only at the preview’s right edge. Adding or removing it uses the existing **Keep macOS Control Strip** setting, and it never appears as a placeholder item in the saved profile.

Drag feedback was adjusted for drops beyond the visible Touch Bar area. The user had confirmed dragging the right-edge Control Strip tile into place before the Dock sizing changes below.

The Dock preview now uses the live native app list and icons. Its widget grows to its natural width when space is available, then shrinks icon tiles and gaps to keep every app visible without internal scrolling. The Dock's saved position and other controls' positions stay fixed. The separate Control Strip tile remains right-edge-only and uses the existing **Keep macOS Control Strip** setting.

Date and status previews now use transient content-fit widths so formatted dates and values such as the CPU preview's illustrative `100.0%` are not clipped at the generic width. The preview and placement calculations share the same minimum width, while saved widths and X positions remain unchanged; insufficient room is reported as a placement warning. Native AppKit checks passed for long dates and CPU content at narrowed scales, including automatic-layout constraints.

The final installed build passed `./build-local.sh` and strict code-signature verification, including state/catalog checks, Vite, Swift, and native AppKit Dock-fit, preview-cache, Date/CPU sizing, and automatic-layout checks. All 12 frontend sizing, Dock, and viewport tests passed. Frontend fit fixtures also passed with five and fourteen apps at 76-unit and 520-unit widths; all icons stayed inside the tile with no internal overflow. [The screenshot](../screenshots/dock-fit-fixtures.png) shows editor fixtures only, not the physical Touch Bar. Visual and physical Dock-fit confirmation is pending the user's reopen. Their earlier confirmation that the right-edge Control Strip tile can be dragged into place predates the Dock sizing changes. Permission status for the latest build and physical keyboard/media delivery have not been checked. See the [verification record](../../VERIFICATION.md) for current results.
