# Touch Bar Studio 0.9.0 — Combined System Monitor

The Time & status library now has one System Monitor for CPU usage, GPU usage, memory, and CPU temperature. Choose any readings in Properties; the native control shows selected values in fixed CPU/GPU/memory/temperature order beside a single icon. Full reading names are available in tooltips and accessibility labels. The control width follows the selection and becomes icon-only when all readings are cleared.

The native monitor shares the existing metrics sampler and subscribes only to selected readings. CPU usage has its own serialized tick baseline, which avoids racing the legacy CPU widget and handles wrapping and zero-delta samples safely.

Existing CPU, RAM, GPU, and CPU-temperature controls remain readable. To combine them, select a legacy metric control in the current bar and choose **Combine into System Monitor** in Properties. One undo restores the prior layout. The action combines only the current bar, preserves unrelated control positions and other profiles, and unions readings into an existing monitor when one is present. Imports and other profiles are not rewritten automatically.
