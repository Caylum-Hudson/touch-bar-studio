# Touch Bar Studio 0.10.0 — Resolve fine controls

Touch Bar Studio adds 90 pt inline dials for Resolve Color Bars Lift, Gamma, and Gain, with Y/R/G/B channel selection. Fine is the default and accumulates fractional input until it reaches a whole integer slider step. Normal and Coarse are available in Properties. A 140 pt relative timeline jog is available on the Edit page; Fine accumulates small movements to frame steps. It selects the Timeline panel and uses bounded frame-step menu actions, without claiming an absolute playhead position.

The editor preview shows three dials and the jog together in a 685 pt custom area, with macOS Control Strip shown separately. Dial values in the editor are illustrative. At runtime, both controls stop on focus/context changes and when the custom Touch Bar is disabled. Color writes require the expected visible Color Bars hierarchy and fresh accessible slider ranges. Jog is Edit-page only.
