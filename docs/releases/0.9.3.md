# Touch Bar Studio 0.9.3 — Live System Monitor sizing

Choose **Fit live content** in System Monitor Properties to size the native control from its current readings. Its frame grows and shrinks as values change, instead of retaining the previous manual width. Entering a numeric width restores manual sizing.

The editor shows the current bar’s matching live title and width, including after restarting Studio. Other profiles, pages, submenus, and unsaved monitor configurations retain illustrative previews. Matching uses current or retained native identities with configuration checks; ambiguous identities are rejected. Live measurements stay out of saved layout geometry, and the existing two-second polling and shared selected-metric sampler remain in use.
