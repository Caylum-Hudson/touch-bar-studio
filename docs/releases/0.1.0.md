## Touch Bar Studio 0.1.0

First prerelease of the custom macOS Touch Bar editor, launcher and photo workspace, built on MTMR Designer and the bundled MTMR runtime.

### What is included

- Custom Touch Bar on/off control in the app and menu bar, remembered across restart.
- Default and complete app-specific profiles, plus recursive submenu editing and runtime Back navigation.
- The visual control palette, properties, presets, JSON import/export and undo/redo.
- App/folder launcher tiles, appearance settings and a folder photo browser.
- Finder Open With support, a Service declaration, and local source build scripts.

### How versions work

Start at **0.1.0**. Use **0.1.1** for fixes/polish, **0.2.0** for meaningful feature updates, and **1.0.0** when core workflows are tested and dependable. Git commits save individual changes; tags and release notes identify finished updates. Published versions are not replaced with different code.

### Illustrated usage

![Layout editor and on/off control](https://raw.githubusercontent.com/Caylum-Hudson/touch-bar-studio/v0.1.0/docs/screenshots/studio.png)

Select a profile, add controls, and use **Apply & Save**. The separate **Touch Bar: On/Off** button applies immediately. The [README](https://github.com/Caylum-Hudson/touch-bar-studio/tree/v0.1.0#screenshots-and-usage) includes additional submenu and appearance screenshots with explanations.

### Build and checks

Follow the [build instructions](https://github.com/Caylum-Hudson/touch-bar-studio/tree/v0.1.0#build-from-source). The local production/native build, editor state checks and native self-test pass. UI checks cover on/off synchronization and restart persistence, submenu editing, native saving and basic photo browsing.

### Why this is a prerelease

Physical Touch Bar display, touch navigation, app switching and global shortcut delivery still need hands-on confirmation. Custom scripts are disabled. A dedicated Finder Quick Action extension and resize-copy tool are not included. The local app uses an ad-hoc signature and is not notarized.
