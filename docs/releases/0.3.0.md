## A clearer control library, with honest availability

Version **0.3.0** reorganises what you can add to your Touch Bar and makes the controls look consistent.

![Redesigned control library](https://raw.githubusercontent.com/Caylum-Hudson/touch-bar-studio/v0.3.0/docs/control-audit/02-redesigned.png)

### What changed

- Everyday sound, display, time and navigation controls come first; connected services and legacy controls live in Advanced & legacy.
- All 41 catalog entries have a clear purpose, capability label and monochrome macOS symbol. Add with **+**, or drag the separate grip.
- Known unavailable scripts, swipe and Sleep controls cannot be newly added from the palette. Imported entries remain exportable.
- The preview no longer invents CPU, battery or weather readings. It is clearly marked as an editor preview.
- Native common buttons, CPU and focus timer use matching symbols. Explicit custom images and alignment now take precedence over built-in defaults.
- Malformed native JSON returns a decode failure instead of crashing. Date drag retains its date-format defaults.

### What was checked

Production frontend/native build, catalog/icon coverage for 41 entries, native decoding for 36 retained controls, expected filtering for five script/swipe entries, JSON/position/profile tests, and optional read-only clock/battery/CPU/focus/volume initialization passed. UI search, Date adding/defaults, removal and saving were checked with the original seven-control layout preserved and the custom Touch Bar Off.

**This is a prerelease.** Decoding is not proof that a physical tap works. Physical controls, granted-permission keyboard/media delivery, hardware changes, services, Automation and older private-system toggles remain unverified. Sleep has no active action in this build. Cmd-Z in a focused search field affects text; editor undo focus routing remains a follow-up.
