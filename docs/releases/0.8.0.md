# 0.8.0 — Even placement

**Auto-place evenly** sits beside the Touch Bar preview. It distributes the current profile or submenu’s controls with equal free gaps, keeps their visual order and configured sizes, and can be undone. If the controls do not fit, an error asks you to remove items and preserves the existing layout.

The fit calculation uses the native custom-region bounds, independent of the Studio window width. Conservative intrinsic widget widths and the Dock’s natural width are converted into the 1085-unit layout; submenu/Resolve navigation is reserved in the same way as the native runtime. The macOS Control Strip remains in its own right-side region. Missing native size or Dock data produces a wait/turn-on message rather than a false no-fit error.

The isolated browser fixture verified arrangement, exact Undo, and unchanged layout JSON after the no-fit error. The final 0.8.0 native build, self-tests, widget checks, strict signing, and version check pass; installed UI review confirms the visible enabled action and granted Accessibility. The user’s saved layout was preserved; action success/Undo/overflow were tested in the isolated fixture.
