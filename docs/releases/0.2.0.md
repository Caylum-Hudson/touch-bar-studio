## Precise placement and a refreshed editor

Version **0.2.0** adds direct placement controls and modernises the darker editor panels.

![Precise placement in version 0.2.0](https://raw.githubusercontent.com/Caylum-Hudson/touch-bar-studio/v0.2.0/docs/screenshots/precise-placement.png)

### Arrange controls

1. Open **Studio** and click **Precise placement** above the preview.
2. Drag a control horizontally or select it and type its **X position** and **Width** in Properties.
3. Use **Apply & Save** to activate the layout. Your positions remain on restart.

The ruler has 1085 design units and scales to the custom Touch Bar width macOS provides. Each app profile and submenu can be arranged separately. Submenu layouts reserve room for Back. Bounds keep controls inside the canvas, and a warning highlights overlaps. **Use automatic alignment** restores the original alignment behavior for the current screen.

### Visual update

The editor uses darker blue-black surfaces, lighter borders, rounded palette tiles and controls, and clearer selection accents. Menus, property fields and the JSON editor have been updated alongside the Touch Bar preview.

### Compatibility and verification

Existing layouts stay in automatic mode until precise placement is selected. The `studioPosition` JSON field is an extension for Touch Bar Studio; older MTMR runtimes can ignore it. The frontend and native runtime both read it.

Production/native build, native coordinate decoding/clamping, frontend position/bounds/overlap tests and JSON round trips pass. The rebuilt native app shows version 0.2.0 and the new controls; live placement changes update the JSON, and saved user positions survive the rebuild. Actual physical spacing and submenu Back reserve still require device confirmation, so this remains a prerelease.
