# Touch Bar Studio 0.11.0 — Learned Resolve HDR adjustment dial

Add **Resolve Adjustment Dial** to a Resolve Color page layout. Give it a short Touch Bar label and choose a change step (.01 by default, .1, or 1). Click **Learn in Resolve**, then double-click the intended HDR Exp or Sat value while its zone is visible. The capture stores the value’s location relative to the HDR panel and leaves the displayed value unchanged. The dial can find the captured zone row using the HDR panel navigation arrows. It stops if the panel shape changes or its arrows and final row cannot be verified.

After learning, **Test −** and **Test +** each adjust one step and verify the committed readout. The UI exposes .01 or coarser steps because Resolve’s static readout is verified to two decimal places. A custom label changes the dial’s Touch Bar name while Properties continues to show the captured HDR target. This does not create separate Blacks, Whites, Shadows, or Highlights parameters; it adjusts the exact Exp or Sat value learned.

The collapsed Control Strip preview now fits inside the 30 pt face without clipping. HDR preview values remain illustrative; live values come from the installed Touch Bar control.

## Verification

- Frontend tests cover the new control definition, binding serialization and workspace restoration, invalid binding rejection, stale-operation guards, and native-width preview sizing.
- Physical Touch Bar interaction and installed Resolve writes require live root QA. No user layout is changed by creating or previewing this widget; bind it in the user’s Color page layout only when intended.
