# Expanded sliders and spacing

Version **0.4.0** reshapes the editor around the Touch Bar preview and adds a spacing option for numeric layouts. This is a source prerelease; physical Touch Bar tap delivery and volume hardware adjustment remain unverified.

### Native slider presentation

Volume and brightness controls are represented by compact icons on the Touch Bar. Tapping an icon is intended to replace the current bar with a full-width slider view containing a Back button and minimum/maximum endpoint symbols. The editor preview includes the expanded state for review.

Brightness lookup selects an active built-in display instead of passing display ID `0`. A reversible write/readback passed on built-in display ID 1: brightness changed from `0.5093718` to `0.5393718`, read back at that value, then was restored and read back at `0.5093718`. The earlier CoreDisplay path returned a misleading `1.0` and did not change the observed brightness; the implementation now uses DisplayServices. Physical Touch Bar tap delivery and volume hardware adjustment remain unverified.

### Editor and spacing

- The control library moves below the Touch Bar preview and replaces the JSON editor panel; it no longer occupies the left sidebar.
- A spacing option sets an edge gap in the numeric layout.
- Dragging within 10 design units of a neighboring configured gap can snap to it. Farther placements remain free.
- Numeric item positions and the spacing value are saved with the layout.

The built-in brightness write/readback passed and was restored, as described above. Physical Touch Bar tap delivery and volume hardware adjustment remain unverified.
