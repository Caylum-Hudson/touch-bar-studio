# Touch Bar Studio 0.10.1 — Resolve assignment guidance and preview calibration

The Resolve dial Properties panel now uses one **Adjustment** menu for Lift, Gamma, and Gain on Y, Red, Green, or Blue. The saved `parameter` and `channel` fields remain compatible with existing layouts. The panel explains that the dial needs the Resolve Color page with Primaries Color Bars open, warns when the dial is assigned to another page layout, and identifies HDR Color Wheels as unsupported because they expose no stable settable sliders.

The editor preview keeps the control face at 30 pt high, with the precise-placement ruler and bezel outside that face. **Preview size** in Layout settings is an editor preference from 50% to 200%; 100% is the native preview scale. Narrow windows fit the same uniform scale down, and fullscreen does not enlarge the default preview to fill the window. The scale is applied to pointer mapping as well as drawing.

## Verification

- Source tests cover default scale, explicit calibration, narrow-window fit, pointer mapping, and supported calibration bounds.
- Physical Touch Bar dial/jog gestures still require confirmation on hardware. HDR parameters remain unsupported.
