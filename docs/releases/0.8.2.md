# 0.8.2 — Import validation and bounded photo work

Workspace import now validates every profile and Resolve page before changing editor state. Malformed controls produce an error and leave the current editor intact. Enabled app profiles need a bundle identifier; missing frontmost app information uses Default rather than matching a malformed app profile.

Photo scans and thumbnail decoding now run on a queue limited to two concurrent operations. New scans supersede older work, stopped WebKit tasks receive no late callbacks, and only the latest successful scan installs the photo lookup map. A failed scan preserves the previous map. Thumbnail requests capture their file URL before background work, so a later scan cannot redirect them. Photo thumbnails remain bounded to 420px. Selected control icons use ImageIO downsampling to at most 512px with alpha preserved, without rewriting the source image.

The embedded editor now presents native file pickers for HTML file inputs and native confirmation/alert dialogs. Workspace replacement requires an explicit Continue choice; Cancel is the default.

Pomodoro timers now release with their widgets, derive remaining time from a deadline, and allow 100ms scheduling leeway. After initial workspace loading, periodic status responses omit the unchanged workspace payload. No CPU or memory benchmark improvement is claimed.

The installed build passes 33 Node/staging tests, reducer/state/catalog checks, native self-tests including stopped/superseded/failed photo requests and 20 widget lifecycle cycles, read-only widget checks, and strict signature verification. Prebuild and postbuild SHA-256 hashes confirm both saved workspace files are unchanged. Installed UI review confirms that the native import picker opens and malformed controls produce a visible error while retaining all six current controls. [Rejected import screenshot](../screenshots/rejected-import-0.8.2.png) records the editor UI, not physical Touch Bar pixels. Four synthetic images loaded, filename filtering returned one image, and the selected 1200×800 image showed its thumbnail and 1.500 ratio. The current build reports Accessibility granted. No Apply & Save was used during these tests; both saved workspace hashes remained unchanged.
