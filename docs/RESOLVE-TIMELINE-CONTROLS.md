# DaVinci Resolve timeline controls

The palette includes buttons for J/K/L playback, single-frame and edit navigation, timeline start and end, In and Out points, and snapping. Each is a static button with an editable key action and a dedicated macOS symbol. The controls are filtered to the DaVinci Resolve bundle ID (`com.blackmagic-design.DaVinciResolve`) through MTMR's existing `matchAppId` support. Keyboard delivery requires the app's Accessibility permission.

The defaults follow Blackmagic Design's [DaVinci Resolve 20 Editors Guide](https://documents.blackmagicdesign.com/UserManuals/DaVinci-Resolve-20-Editors-Guide.pdf?_v=1757574010000): J/K/L control reverse, stop, and forward playback; Left/Right move one frame; Up/Down move to previous/next edit; Home/End move to timeline start/end; I/O set In/Out points; N toggles timeline snapping. Resolve lets users customize keyboard mappings, so edit the shortcut in the Properties panel if the local mapping differs.

The installed build passed catalog/default serialization checks for all 53 controls; native decoding retained 48 and filtered five export-only controls. Six permission-state tests passed, including granted, denied, and unknown Accessibility states for all Resolve controls. Browser QA confirmed the Play Reverse control's J selector, keycode 38, Resolve app filter, and permission status; the temporary test item was deleted and the profile reloaded. [Resolve widget library screenshot](screenshots/resolve-widget-library.png) shows the editor in localhost, not the native Touch Bar. Physical Touch Bar presentation and live Resolve key delivery remain unverified.
