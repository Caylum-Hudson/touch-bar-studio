# DaVinci Resolve timeline controls

The palette includes buttons for J/K/L playback, single-frame and edit navigation, timeline start and end, In and Out points, and snapping. Each is a static button with an editable key action and a dedicated macOS symbol. The controls are filtered to the DaVinci Resolve bundle ID (`com.blackmagic-design.DaVinciResolve`) through MTMR's existing `matchAppId` support. Keyboard delivery requires the app's Accessibility permission.

The timeline defaults follow Blackmagic Design's [DaVinci Resolve 20 Editors Guide](https://documents.blackmagicdesign.com/UserManuals/DaVinci-Resolve-20-Editors-Guide.pdf?_v=1757574010000): J/K/L control reverse, stop, and forward playback; Left/Right move one frame; Up/Down move to previous/next edit; Home/End move to timeline start/end; I/O set In/Out points; N toggles timeline snapping. Resolve lets users customize keyboard mappings, so edit the shortcut in the Properties panel if the local mapping differs.

Resolve profiles can also keep separate layouts for each page. The optional setup seeds Edit with the 12 timeline controls and Color with eight editable shortcuts. The Color defaults were checked against the DaVinci Resolve 21.1.1 manual installed with Resolve: Option+S/P/L/O adds Serial, Parallel, Layer, and Outside nodes; Command+D toggles the selected node; Option+D toggles all nodes; Option+Shift+semicolon/apostrophe selects the previous/next node. These commands change the node graph or its enabled state. Keyboard delivery requires Accessibility permission, and shortcuts can be edited for local key mappings.

Resolve's eight pages are available in Studio and runtime selectors. Unconfigured pages use the profile fallback until the user creates a separate copy. Automatic page selection reads the selected page control from Resolve's standard window and requires Accessibility access. The manual page selector remains available when detection is unavailable or ambiguous. Studio's editing selector selects the layout to edit; it does not switch Resolve's own page.

The installed build passed catalog/default serialization checks for all 53 controls; native decoding retained 48 and filtered five export-only controls. Six permission-state tests passed, including granted, denied, and unknown Accessibility states for all Resolve controls. Browser QA confirmed the Play Reverse control's J selector, keycode 38, Resolve app filter, and permission status; the temporary test item was deleted and the profile reloaded.
